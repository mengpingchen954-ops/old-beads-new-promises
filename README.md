# 旧珠新约 · The Bead Atelier

一间把故事重新串起的小店。原创手绘风、Three.js 正交镜头的 2D 顺序解谜游戏。十二份委托、三位顾客、一段有结尾的旧物故事。

当前交付为浏览器体验版，尚不是可在微信开发者工具中提审的原生小游戏包。

## 手串视觉

参考用户提供的水晶圆珠方向，采用紧密的十八珠手串：月光石底珠已排好，玩家依次补入彩色配珠。底珠用于成品搭配，不计入料杆与关卡供需；原有十二关规则、存档和操作保持兼容。工作台、封面、交付展示和收藏册使用一致的珠位布局，并加入少量金属隔片与小吊环。

粉晶、绿幽灵、金发晶、月光石、海蓝宝、紫水晶使用原创程序绘制的球体纹理，表现侧向穿孔、光泽、棉絮或发丝状内含物。它们是风格化游戏美术，不是商品照片或真实矿物光学模拟。参考照片没有作为游戏资产上传。

## 串珠手感与声音

- 拿起时抬升，拖动时珠子跟手并带有投影；碰到其他可见珠子时有短促的让位回弹与轻碰声。错误落点会回到原处，不更改谜题状态。
- 珠子沿短弧飞往准确的手链珠位，接触时才播放碰响；落位回弹、线圈振动和邻珠轻晃在短时间内自然衰减。支持快速输入与中途撤销，特效不阻塞逻辑。
- 六种珠子使用各自的瞬态与阻尼共振，木盘接触有较低沉的碰响；一条手链串好和委托交付有独立的收束弦音。全部为原创程序合成，无外部音频依赖。
- 右上角喇叭一键静音；工作台下方“声音调校”可调整音量、关闭舒缓拨弦背景声、试听碰响。设置与旧存档兼容，切后台暂停声音。尊重系统减少动态效果偏好。

## 游玩

- [浏览器直接玩](https://mengpingchen954-ops.github.io/old-beads-new-promises/)
- 鼠标或触屏点选料杆左端的珠子，再点需求相符的手链或空暂存格；亦可拖放。
- 暂存珠只能串入手链，不能放回料杆。用完所有珠子、完成两条手链即可交付。
- 无限撤销与重开，无计时、付费或广告。提示会指出一个可继续完成的行动。
- `Tab` / `Enter` 操作按钮，`Z` 撤销，`Esc` 关闭普通弹窗或取消选择，`F` 全屏。
- 委托进度、当前操作与声音开关保存于此浏览器的本地存储。清除网站数据会丢失进度。

## 本地运行

需要 Node.js 22.12+（或 Vite 8 支持的新版本）。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址；不可直接双击 HTML 启动 ES modules。

```sh
npm test
npm run build
npm run preview
```

`dist/` 是可部署到任意静态站点的生产文件；资源使用相对路径，支持仓库子目录。GitHub Actions 在 main 更新后测试、构建并发布 Pages。

## 测试

`npm test` 检查全部十二关的材料守恒、可解性、非法操作、阻塞、不可变状态与存档输入，以及十八珠闭环的珠位映射和六种 PNG 纹理解码。

```sh
npx playwright install chromium
node tests/playthrough.mjs
node tests/feel.mjs
```

浏览器端检查十二关通关、结局、收藏、存档续玩、点选与拖放、手机触屏、重来、撤销、提示、阻塞恢复和尺寸变化。可用 `GAME_URL` 指向预览或公开站点；截图输出到不提交的 `artifacts/`。

手感专项检查接触反馈、错误回弹、落位时序、拖动取消、飞行中撤销、快速复用暂存格、声音设置持久化、静音、真实触屏取消和减少动态效果。离线渲染实际音频合成器，校验六种音色有输出、互异、无削波且尾音衰减；生成 `artifacts/bead-sound-demo.wav` 供试听。波形检查不能替代手机扬声器与耳机的主观听感验收。

## 实现与资产

- `src/model.js`：纯游戏规则与深度优先解法搜索，不依赖 Three.js。
- `src/renderer.js`：单一 Three.js canvas，正交 2D 镜头、纹理珠子、工作台与短动作动画。桌面左右布局、手机竖向布局；静止时不持续重绘，像素比上限 2。
- `src/main.js`：DOM 菜单与无障碍操作层、故事、收藏、保存、合成音效。
- `src/levels.js` / `src/content.js`：固定关卡与原创角色、订单和完整故事。
- `public/art/`：十二个原创 SVG 美术资源，其中六种圆形水晶珠以 SVG 内嵌 PNG 形式提供（球体明暗、内含物、高光与侧向穿孔）、三位顾客、桌面、封面和标记。珠串参考了用户提供的水晶/文玩手串方向，但没有把参考照片直接放入游戏；可直接用于 Three.js 纹理或网页图像。
- `scripts/create-art.mjs`：可复现的原创环境、人物与封面绘制源；`scripts/crystal-art.mjs`：不依赖图片库的水晶球体纹理与 PNG 生成；`src/jewelry.js`：统一手串珠位；`scripts/create-levels.mjs`：带解法校验的固定关卡生成源。

最初请求 imagegen，但当前工具不可用；用户随后选择使用统一原创手绘风美术，不调用付费 imagegen CLI。作品使用代码绘制素材，不声称这些图片来自 imagegen。没有使用外部图片、字体 CDN、角色 IP 或在线游戏服务。

不加入与委托解谜无关的敌人、武器、战斗和掉落系统。交付奖励是实际珠序对应的手链与回访来信，收藏可重看与重玩。

浏览器需支持 WebGL 2。针对 Chromium 桌面与模拟手机进行了验证；尚未覆盖所有实机浏览器，关卡难度和剧情吸引力仍待目标玩家试玩。

微信发售前仍需：用微信 canvas UI 替换当前 DOM 交互层，适配触摸、存储、生命周期与音频，转换并实测 SVG 纹理，再完成开发者工具和 Android/iOS 微信真机测试。规则层可以复用。当前没有接入微信账号、广告或付费系统，也没有声称已满足微信平台提审要求。
